이번 주차에는 Spring Data JPA를 써서 엔티티 매핑하고 실제 DB를 연동하는 핵심 기능들을 쭉 훑어봤습니다.

가장 중요했던 건 자바 객체랑 관계형 데이터베이스(RDB) 사이의 벽을 허무는 작업이었는데요. @Entity랑 @Table 써서 클래스랑 테이블을 매핑하고, @Id나 @GeneratedValue로 기본키(PK) 전략을 어떻게 가져갈지 직접 설정해봤습니다. 특히 Hibernate 버전이 올라가면서 예전처럼 Dialect를 일일이 지정하지 않아도 자동으로 잡아주는 부분이나, 쿼리 로그 확인하는 설정 같은 실무적인 부분도 같이 다뤘습니다.

연관 관계 매핑 부분도 꽤 비중 있게 다뤘는데, 주문(Order)이랑 회원(Member) 관계를 @ManyToOne으로 엮으면서 DB 외래키를 객체지향적으로 어떻게 풀어내는지 공부했습니다. 여기서 중요한 게 성능 문제인데, FetchType.LAZY를 써서 불필요한 데이터를 미리 가져오지 않도록 최적화하는 감각을 익히는 게 핵심이였던 것 같네요.

그리고 단순히 데이터를 넣고 빼는 걸 넘어서, 엔티티 안에 updateInfo 같은 비즈니스 로직을 직접 넣는 도메인 모델 패턴도 적용해봤습니다. 이렇게 하니까 서비스 계층 코드가 훨씬 깔끔해지고 객체 자체가 살아있는 느낌이 들더라고요. 중간중간 Dialect 에러나 @Id 누락 같은 버그들을 잡으면서 JPA가 내부적으로 어떻게 돌아가는지 삽질(?)도 좀 했지만, 덕분에 에러 로그 보는 법이랑 설정값 맞추는 법은 확실히 손에 익은 주차였습니다.

담 주에는 아마 이걸 바탕으로 레포지토리 계층 만들고 실제 API까지 뚫어보는 작업을 할 텐데, 이번에 잡은 엔티티 구조가 탄탄해야 나중에 고생 안 할 것 같습니다. 전반적으로 JPA의 기초 체력을 기르는 시간이라 꽤 유익했습니다.
